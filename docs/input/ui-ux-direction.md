# UI/UX方針

## 1. 全体の方向性

### デザインテーマ
自然・温かみ・スタイリッシュ
（dancyuほど作り込まれすぎず、サライほど渋すぎない。映画を見ているようなエモーショナルな体験）

### キーワード
- スタイリッシュ
- 温かみ（ナチュラル）
- エモーショナル
- サクサク感（手軽さ）

### 参考サービス
| サービス名 | 参考にする点 |
|------------|--------------|
| Pinterest | ビジュアルベースのカード型レイアウト、流し見のしやすさ |
| Instagram | 写真が主役となる見せ方、直感的な操作感 |

## 2. ビジュアル

### カラー方針
- メインカラー：料理やお店の写真が最も映える、主張しすぎないナチュラルな色合い（例：オフホワイト、アイボリーなど）
- アクセントカラー：温かみを感じさせる色（過度にポップな色は避ける）
- 背景：コンテンツの邪魔をしないシンプルな背景
- テキスト：視認性が高く、かつスタイリッシュなフォントカラー（真っ黒ではなく、少し柔らかいダークグレーなど）

### タイポグラフィ方針
- 見出し：洗練された印象を与えるフォント
- 本文：読みやすく、エッセイや雑誌のコラムを読んでいるような気分にさせるフォント
- 雰囲気：大人っぽさ、映画のような落ち着き

## 3. UX原則

### 重視する体験
1. **入力の気持ちよさ**：独り言を喋るだけで、魔法のように美しい記事ができあがる「Aha Moment」。
2. **ビジュアルの美しさ**：URLを開いた瞬間に目を引く、写真を中心としたリッチな一覧画面。
3. **読み心地の良さ**：単なるデータではなく、書いた人の「熱量」や「ストーリー」がスッと入ってくる体験。

### 避けたいUX
1. 入力項目が多すぎて、登録するのが面倒になること（既存の食べログ投稿のような手間）。
2. 文字や情報が多すぎて、事務的なデータベースのように見えてしまうこと。
