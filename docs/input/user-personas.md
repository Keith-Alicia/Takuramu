# ターゲットユーザー

## メインペルソナ

### 基本情報
- 名前（仮）：食通のインフルエンサー・口コミハブ（教える側）
- 職業：会社員・フリーランスなど
- 生活環境：都市部在住。外食の頻度が高く、美味しいお店のストックが頭の中にある。

### 1日の流れ
仕事やプライベートでよく外食をする。友人との飲み会や出張先でも積極的にお店を開拓。友人からLINEで「今度〇〇に行くんだけど、いいお店ない？」と頻繁に聞かれる。

### 課題・ペイン
お店を聞かれた時、食べログのURLだけ送るのは味気ない。自分の「ここが良かった！」という熱量やストーリーを伝えたいが、毎回LINEで長文を打ったり写真を探したりするのが非常に面倒くさい。

### 現在の解決方法
頑張って食べログのURLと写真を探し、LINEで文章を添えて送っている。

### 求めているもの
自分の体験や熱量を、手間をかけずにリッチな形（美しいWebページ）で相手に共有できるツール。

### このプロダクトを使う瞬間
- 新しい良いお店を見つけて、忘れないうちに自分のポートフォリオに追加したい時（独り言で記録）。
- 友人から「〇〇の美味しいお店教えて」とLINEで聞かれた時（ポートフォリオのURLを送信）。

### 情報収集の方法
実際の食べ歩き、信頼できる知人からの口コミ、SNS。

## サブペルソナ

### 基本情報
- 名前（仮）：お店を探している友人（受け取る側）
- 生活環境：デートや会食、旅行などで「ハズさないお店」を知りたい。

### 課題・ペイン
食べログの点数だけでは本当に良いお店か（自分に合っているか）分からない。信頼できる友人の「生の声」が欲しい。

### 現在の解決方法
食通の友人にLINEで直接聞く。

### 求めているもの
単なるお店のデータではなく、「なぜそのお店が良いのか」という友人のストーリーや文脈を含んだ情報。

### このプロダクトを使う瞬間
友人から送られてきたURL（ポートフォリオ）をスマホで開いた時。美しい写真とストーリーを読んで感動し、「自分もこれを作ってみたい」と思う瞬間。

## 非ターゲット
- 自分の体験やストーリーを語ることに興味がなく、単に備忘録として店名だけメモできればいい人。
- 全く外食をしない人。
