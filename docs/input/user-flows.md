# ユーザーフロー

## 1. オンボーディングフロー
### 新規登録
1. ランディングページにアクセス
2. SNS（Google/LINE等）でログイン
3. 最初のポートフォリオ（例：「お気に入りの中華」）を作成

### 初回利用（お店の記録）
1. ポートフォリオ画面で「＋追加」ボタンをタップ
2. 食べログ等のURLをペースト
3. 写真をカメラロールから選択
4. マイクボタンを押し、「ここは麻婆豆腐が絶品で〜」と独り言を録音
5. AIが整形した紹介記事が生成され、プレビューを確認・保存

## 2. メインフロー
### お店の共有（LINE等へ）
**目的：** 友人におすすめのお店を教える

**フロー：**
1. アプリを開き、対象のポートフォリオ（例：横浜の中華）を選択
2. 「共有」ボタンをタップし、URLをコピー
3. LINE等で友人にURLをペーストして送信

**成功条件：** 友人がURLを受け取り、問題なくリッチな画面を閲覧できること。

---

### 受信者の閲覧と新規登録
**目的：** 共有されたURLを見て感動し、自分も使い始める

**フロー：**
1. LINEで受け取ったURLをスマホでタップ
2. 美しいPinterest風のカード一覧（お店リスト）が表示される
3. 気になるカードをタップし、友人のストーリー（AI生成文）を読む
4. 画面下部の「自分も作ってみる（無料）」ボタンをタップ
5. 新規登録画面へ遷移

**成功条件：** 受信者がスムーズに閲覧体験を楽しめ、アプリの魅力に気づいて登録アクションを起こすこと。

## 3. その他のフロー
### 記事の修正
1. ポートフォリオからお店の詳細を開く
2. 編集ボタンをタップ
3. AIが生成したテキストを直接タイピングして微修正する
4. 保存
