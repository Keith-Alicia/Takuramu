## 機能詳細

### 記事自動生成機能
**概要：**
ユーザーの「独り言」レベルの音声データを受け取り、LLMを用いて魅力的で読みやすい飲食店紹介記事に整形する。

**ユーザーストーリー：**
「教える側として、音声で適当に話すだけで、しっかりとした文脈のある紹介文を作成したい。なぜなら、スマホで長文をタイピングするのは非常に面倒だから。」

**入力：**
- 音声データ（または音声認識後のベタテキスト）
- 食べログ等のURL
- 写真

**出力：**
- 整形されたタイトルと紹介文（エモーショナルで温かみのあるトーン）

**受け入れ条件：**
- [ ] 音声データから文字起こしができること
- [ ] 文字起こしされたテキストをLLMが自然な文章に整形すること
- [ ] 数秒以内に生成が完了すること
