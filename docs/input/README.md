# 飲食店ポートフォリオアプリ（仮）

## 概要
独り言（音声）と写真・食べログURLを入力するだけで、AIがエモーショナルな飲食店紹介記事（ポートフォリオ）を自動生成し、URL一つでサクッと共有できるアプリ。

## 解決する課題
友人におすすめの飲食店を教える際、食べログURLだけでは味気ないが、イチから文章を打ったりブログを書いたりするのは面倒すぎるという課題。

## ターゲットユーザー
頻繁に美味しいお店を聞かれる「食通・インフルエンサー」と、その熱量ある情報を信頼する「友人」。

## 主要機能
- 音声入力とAIによるリッチな紹介記事の自動生成
- Pinterest/Instagram風の美しいビジュアルベースの閲覧UI
- URL一つでの簡単なポートフォリオ共有機能
